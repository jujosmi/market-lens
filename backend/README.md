# Backend

This directory contains the isolated FastAPI demonstration backend. It uses local synthetic fixtures, a pinned Python research-function snapshot, and an optional server-side SEC EDGAR adapter. It does not import Streamlit or connect to Yahoo Finance or Alpaca.

For dependency setup, loopback-only startup, SEC User-Agent configuration, testing, and known limitations, use the root [README](../README.md). The required Python lockfile is `requirements-lock-py314.txt`.
