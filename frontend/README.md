# Frontend

This is the Jujosmi Trade UI 2.0 React client. Use the package lockfile and root instructions:

```powershell
npm ci
npm test
npm run build
npm run dev
```

The root [README](../README.md) documents the frontend/backend demo, optional Supabase configuration, privacy boundaries, and local startup scripts. Do not put Supabase secret or service-role keys in frontend environment variables.
